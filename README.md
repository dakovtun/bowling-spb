# Боулинг СПб

Независимый гид по боулинг-клубам Санкт-Петербурга: каталог с фильтром по районам, карточки клубов с ценами, часами
работы и контактами.

## Стек

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Данные хранятся статически в `lib/clubs.ts` (без базы данных — каталог небольшой и обновляется вручную)

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
