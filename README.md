# Боулинг СПб

Независимый гид по боулинг-клубам Санкт-Петербурга: каталог с фильтром по районам, карточки клубов с ценами, часами
работы и контактами. Есть админка для редактирования карточек клубов.

## Стек

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Данные о клубах хранятся в Redis (интеграция Upstash Redis / бывший "Vercel KV") и редактируются через встроенную
  админку `/admin`. `lib/clubs.ts` содержит `SEED_CLUBS` — начальный набор данных и запасной вариант на случай, если
  хранилище недоступно или ещё не подключено (тогда сайт и локальная разработка продолжают работать как раньше).

## Разработка

```bash
npm install
npm run dev
```

Без подключённого хранилища сайт полностью работает на `SEED_CLUBS` из `lib/clubs.ts` — этого достаточно для локальной
разработки вёрстки/логики. Для работы админки и сохранения изменений нужно хранилище — см. ниже.

## Подключение хранилища (Redis) и админки

1. **Создайте базу.** В Vercel Dashboard откройте проект → Storage → Marketplace Database Providers → добавьте
   Upstash Redis (или используйте уже существующий Vercel KV, если он у вас остался — переменные окружения совместимы).
2. **Скопируйте переменные окружения.** На странице созданной базы нажмите «Copy Snippet» / откройте вкладку `.env.local`
   и скопируйте значения в `.env.local` в корне проекта (см. `.env.example` — поддерживаются оба варианта названий:
   `KV_REST_API_URL`/`KV_REST_API_TOKEN` или `UPSTASH_REDIS_REST_URL`/`UPSTASH_REDIS_REST_TOKEN`).
3. **Задайте пароль админки** в `.env.local`:
   ```
   ADMIN_PASSWORD=ваш-пароль
   ADMIN_SESSION_SECRET=любая-длинная-случайная-строка
   ```
   Сгенерировать секрет: `openssl rand -hex 32`.
4. **Перенесите стартовые данные в хранилище** (один раз):
   ```bash
   npm run db:seed
   ```
   Скрипт ничего не перезапишет, если в хранилище уже что-то есть — только заполнит его в первый раз. Принудительная
   перезапись данными из `lib/clubs.ts`: `npm run db:seed -- --force`.
5. **На проде (Vercel)** повторите шаги 2–3 в Project Settings → Environment Variables, затем задеплойте — сборка сама
   подхватит переменные.
6. Откройте `/admin` на сайте, войдите паролем из `ADMIN_PASSWORD` — там можно добавлять, редактировать и удалять
   карточки клубов.

**Если хранилище не подключено** — например, только начинаете работу с проектом — раздел `/admin` тоже откроется, но
попытка сохранить изменения вернёт ошибку («хранилище не настроено»): под капотом `lib/db.ts` требует хотя бы одну из
пар переменных окружения для записи (для чтения он и без них тихо откатывается на `SEED_CLUBS`).
